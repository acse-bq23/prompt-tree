# 恢复与边界

status 和 prepare --run 读取合同、事件链及被引用产物，不发起模型调用。同一 request-id 重发不会再执行；输入改变时返回 REQUEST_CONFLICT。

- baseline_required：先完成基准的 Search 与 Validation；配置原始路径时同样完成原始基准。
- budget_exhausted：停止探索，选择已有完整验证的版本交付；更改预算需要新实验。
- contract_changed / tool_changed：保存已有产物，核实变化后建立新实验。既有记录仍可用于审阅。
- unknown_execution：此前命令可能已产生远程调用或留下执行。保留预留，停止自动重试；先在原服务确认状态和成本。
- integrity_error：保留异常目录，不丢弃尾记录或改写事件链。先检查缺失产物、部分写入与外部改动。
- busy：存在活跃写入者。先等其结束；工具仅自动回收已确认进程不存在的锁。

v0.1 可以从已确认结果继续，重建报告并恢复同一实验；对未知远程任务没有自动对账或取消接口。外部确认完成后保留原证据，另建已核算预算的任务，不能手工删掉预留来重跑。

纯渲染器、项目执行器与环境依赖按合同固定；工具只约束经过自身的操作。共享同一用户文件权限的宿主仍能绕过这些约束，本地哈希也不能提供抵御该主体的不可篡改保证。

模型和数据为 mock 时，真实目标模型调用为 0，模拟调用另计。以模拟评分验证接入与控制逻辑，不据此判断真实业务效果。
